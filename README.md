# TinyShift ⚡

TinyShift is a smart micro-life assistant that tells you what to do 
right now — based on your city's live weather, your current mood, 
and how much time you have available.

## What It Does

Most weather apps just show you the weather.
TinyShift actually decides what you should do with it.

Enter your city, pick your mood and available time — TinyShift 
combines real-time weather data with AI to give you one clear, 
personalized suggestion for your next 10, 30, or 60 minutes.

## Features

- 🌦️ Live weather data — real-time temperature, humidity and conditions
- 🤖 AI-powered suggestions — human-like, context-aware responses
- 😴 Mood selector — Lazy, Productive, or Fun
- ⏰ Time-aware — suggestions fit exactly in your available time
- 🎲 Surprise Me — let the app decide everything for you
- 🔒 Secure — API keys hidden server-side, never exposed

## Tech Stack

- HTML, CSS, JavaScript
- OpenWeatherMap API
- Groq AI API (Llama 3.3-70b)
- Vercel Serverless Functions
